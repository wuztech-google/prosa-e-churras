# Prosa e Churras BBQ — site

Site de página única (Início, Sobre, Contato) feito em React + Vite, pronto para a Netlify.

## Antes de publicar
O WhatsApp já está configurado em `src/constants.js` ((11) 96743-2647). Para trocar, edite `WHATSAPP_NUMERO`
(DDI + DDD + número, só dígitos. Ex: `5511987654321`).

## Netlify
- Build command: `npm run build`
- Publish directory: `dist`
(já configurado no arquivo `netlify.toml`)
